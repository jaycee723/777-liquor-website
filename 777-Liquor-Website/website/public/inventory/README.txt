================================================

How To Update Cooler Door Products & Prices (3 Simple Steps):

1. Open "cooler-door-inventory.xlsx" in Microsoft Excel, Apple Numbers, or Google Sheets.
2. Add, edit, or remove rows using these simple columns:
   - Product Name   (Example: Bud Light 12pk 12oz Cans)
   - Brand          (Example: Bud Light)
   - Category       (Beer, RTD, Spirits, Wine, or Beverages)
   - Size           (Optional: 11oz, 12oz, 16oz, 6pk, 12pk, 750ml, 1 L, 1.75 L)
   - Price          (Example: 16.99)
3. Save and replace "cooler-door-inventory.xlsx" right here in this inventory folder.

Notes:
- Capitalization is normalized automatically on the website (Title Case words, attached lowercase "11oz", spaced uppercase "1 L").
- Brand logos are linked automatically from public/images/brands using the Brand column.
- Keep the file named "cooler-door-inventory.xlsx" so the Cooler Door page loads it automatically.
